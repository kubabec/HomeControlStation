Detailed Description

Owns the runtime device catalog and orchestrates initialization, configuration, and service calls.

The concrete type set and factory wiring are supplied by the generated device registry. The manager owns every instance through the Device interface, refreshes public descriptions for the UI, persists the common NVM configuration, and routes service calls without depending on concrete device classes.
